# Ecommerce Sentiment Analyzer

A Flask-based e-commerce web application that lets users browse products, submit reviews, and analyze customer feedback with sentiment classification.

## Features

- User registration and login
- Product browsing
- Customer review submission and editing
- Sentiment classification for reviews
- Sentiment analytics
- SQLite database storage
- Test suite and project scripts

## Tech Stack

- **Backend:** Python, Flask
- **Database:** SQLite, SQLAlchemy
- **Frontend:** HTML, CSS, JavaScript
- **Sentiment Analysis:** Python NLP / sentiment-analysis components

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Nitinkamat07/Ecommerce-Sentiment-Analyzer.git
cd Ecommerce-Sentiment-Analyzer
```

### 2. Create and activate a virtual environment

Windows:

```bash
python -m venv venv
venv\\Scripts\\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

Open the local URL printed in your terminal to use the application.

## Purpose

This project explores how sentiment analysis can be integrated into an e-commerce application to organize customer feedback and help understand product reviews.
